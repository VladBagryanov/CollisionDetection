# Frontend для поиска в внутренней документации

Веб-интерфейс для поиска информации в корпоративных документах с использованием RAG (Retrieval-Augmented Generation).

## Возможности

- 🔍 Поиск по внутренним документам компании
- 📚 Отображение источников с цитатами
- 📊 Показатель уверенности в ответе
- 🎨 Современный и отзывчивый интерфейс
- ⚡ Быстрый поиск с использованием Neo4j графа знаний

## Установка и запуск

### Предварительные требования

1. Убедитесь, что Neo4j запущен на `bolt://localhost:7687`
2. Установлены все зависимости основного проекта
3. Python 3.8+

### Запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите Flask сервер:
```bash
python app.py
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## API Endpoints

- `GET /` - Главная страница
- `POST /api/search` - Поиск в документах
- `GET /api/status` - Статус сервера
- `POST /api/init` - Принудительная инициализация графа

### Пример запроса поиска

```json
{
    "question": "Как правильно запустить производственную линию?",
    "data_path": "input_data",
    "chunker": "basic"
}
```

## Устранение неполадок

### Ошибка подключения к Neo4j
- Убедитесь, что Neo4j запущен
- Проверьте настройки подключения в `app.py`

### Ошибка импорта модулей
- Убедитесь, что основной проект находится в родительской директории
- Проверьте, что все зависимости установлены

### Граф не инициализирован
- Используйте endpoint `/api/init` для принудительной инициализации
- Проверьте логи сервера для диагностики
