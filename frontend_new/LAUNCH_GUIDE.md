## 🚨 Устранение неполадок

### Проблема: Сервер не запускается

**Решение:**
```bash
# Проверьте, что порт свободен
netstat -tulpn | grep :8000
netstat -tulpn | grep :5000

# Убейте процессы, если нужно
sudo kill -9 $(lsof -t -i:8000)
sudo kill -9 $(lsof -t -i:5000)
```

### Проблема: Ошибки импорта в app.py

**Решение:**
```bash
# Убедитесь, что основной проект в родительской директории
ls /home/igor/projects/CollisionDetection/

# Установите зависимости основного проекта
cd /home/igor/projects/CollisionDetection
pip3 install -r requirements.txt
```

### Проблема: Neo4j недоступен

**Решение:**
```bash
# Запустите Neo4j
sudo systemctl start neo4j
# или
neo4j start

# Проверьте подключение
neo4j status
```
